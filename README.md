# signus

블라인드 신호 복조기. PCM/IQ 파일을 넣으면 **제원(중심주파수·심볼레이트·변조방식·롤오프)을 자동 탐지**하고
복조해 **시간순으로 재생되는 성상도**로 보여줍니다. 점이 뭉치면 성공.

**광대역 캡처**(여러 신호가 주파수축에 나란히 뜬 수집 파일)는 `signus survey`가 **모든 신호를 탐지·분리**해
하나씩 복조합니다 — 스펙트로그램에서 신호별 상자를 찾고(파워스펙트럼 기반), 각 채널을 기저대역으로 떼어내
기존 복조 엔진에 넣습니다. 아날로그 FM 음성·순수톤처럼 복조 대상이 아닌 신호는 성상도에 억지로 맞추지 않고
그대로 분류해 보고합니다.

의존성은 **numpy, scipy 단 둘** — 웹 UI는 파이썬 표준 라이브러리 서버로 동작하며 외부 리소스(CDN·폰트)
요청이 전혀 없어 격리망에서 그대로 돌아갑니다.

## 설치 & 실행

```bash
python3 -m venv .venv
.venv/bin/pip install numpy scipy          # (개발용: pytest ruff 추가)
.venv/bin/pip install -e .                 # 'signus' 명령 등록

signus dataset --out samples               # 변조×샘플타입×장애 30종 + 정답 사이드카
signus analyze samples/16qam.cplx.1000000.16t.pcm  # 단일 신호
signus survey capture.cplx.20000000.16t.pcm        # 광대역: 모든 신호 탐지+복조
signus sweep --tier core                   # 전수조사 (CORE 100% 필수, BER=0)
signus serve                               # 웹 UI → http://127.0.0.1:8000
```

명령어 전체·옵션·출력 읽는 법, 파일명 규약, 테스트 절차, **실신호 결과를 보고하는 형식**은
[`docs/사용법-테스트-보고.md`](docs/사용법-테스트-보고.md).

## 지원 범위

| 계열 | 변조 | 블라인드 탐지 |
|---|---|---|
| PSK | BPSK, QPSK, 8PSK | ✅ |
| QAM | 16QAM, 32QAM(cross), 64QAM | ✅ |
| FSK/CPM | 2FSK, 4FSK, MSK | ✅ (정포락선 게이트 → 주파수 판별) |
| 차동 | D-BPSK, D-QPSK, π/4-DQPSK | 성상도는 부모와 동일 → `--diff` 디맵 |
| — | OQPSK | ❌ 생성 전용 (아래 참조) |

**샘플 타입**: `i8`/`u8`/`i16`/`u16`/`f32`/`f64` × little/big endian × 바이트 내 비트 역순.
baudline 별칭 `8t`(부호) `8o`(오프셋 바이너리) `16t` `16o` 를 파일명에 씁니다. 실수 통과대역(`real`)과 복소(`cplx`) 모두 지원하며 확장자는 둘 다 `.pcm`.

### v3.1 강건성 (전부 자동, 플래그로 표시)
- **반송파 앨리어스 자동 해소**: M제곱 톤은 fs 모듈로 랩되므로 fc는 fs/sym 모듈로만 결정됩니다.
  노이즈 바닥을 뺀 스펙트럼 중심과 가장 가까운 후보(fc + k·fs/sym, k∈[−2,2])를 항상 선택 —
  플래그 임계(0.4fs)를 되돌아 들어오는 깊은 랩까지 해소하며, 정상 추정은 절대 움직이지 않습니다.
- **멀티버스트**: 감지된 모든 버스트를 시간순으로 보고하고 개별 분석. CLI `--burst N`(1부터),
  웹 UI는 버스트 칩 클릭으로 전환.
- **T/2 분수간격 등화기(FSE)**: 심볼간격 등화기가 못 여는 채널(예: 1.5심볼 0.8게인 에코 —
  심볼레이트 폴딩이 단위원 근처에 영점을 만듦)을 클럭 추적된 2 sps 스트림에서 역변환.
  심볼간격 구제가 실패할 때만 시도하고, 등화 후엔 중립(4차) 재분류로 대칭성 오탐도 복구.
- **저 롤오프(α≥0.05) 심볼레이트 폴백**: α<0.1이면 |x|² 라인이 데이터 정크에 집니다.
  전역 피크가 점유대역폭 사전정보 [0.72B, 1.05B] 밖이면 창 내 후보들을 실제 복조해
  lock 경쟁(+5 마진)으로 선택.

### 정직한 한계
- **OQPSK**: 표준 프런트엔드에선 사각 QAM과 모든 특징(C42·진폭 링)이 겹칩니다. 블라인드 클래스로
  넣으면 QAM을 조용히 오분류하므로 채택하지 않았습니다. 후보가 `{qpsk, oqpsk}`로 한정된 경우에만
  `C42 < 0.88`로 구분 가능. 반쪽심볼 지연을 아는 프런트엔드가 있어야 진짜 지원됩니다.
- **π/4-DQPSK**: 4제곱 신호가 심볼당 π씩 돌아 반송파 추정이 `baud/8`을 흡수합니다. 결과적으로
  QPSK로 분류되고 fc가 `baud/8` 만큼 밀리지만, **차동 디맵으로 비트는 정확히 복원**됩니다(BER 0).
- **프리에코 채널** (예: `(0.45e^{-j0.5}, 1.0, 0.3)`): baud 추정·분류·등화가 동시에 무너지는
  케이스로, v3.1의 폴백으로도 복구되지 않습니다. 파이프라인은 낮은 lock으로 정직하게 보고합니다.
- **강한 에코 + QAM**: 2-ray 채널에서 QAM의 4제곱 톤이 묻혀 반송파 추정부터 깨집니다
  (QPSK 2-ray는 FSE로 복구, BER 0).
- **롤오프 α<0.05**: 초과대역폭이 없으면 심볼레이트의 2차 사이클로 정보 자체가 사라집니다(원리적 한계).
- **차동 vs 일반**: DQPSK와 QPSK는 성상도가 동일해 원리적으로 블라인드 구분이 불가능합니다.
  탐지 대상이 아니라 `--diff` 디맵 선택지입니다(대신 회전 모호성이 사라져 비트가 절대적).

## 파일 규약 — 파일명에는 정답이 없다

`이름.<cplx|real>.<샘플레이트>.<샘플타입>[.be][.bitrev].pcm` (옛 `이름_fs…_iq_i16.iq` 도 읽습니다)

정답(변조·fc·baud·SNR·롤오프)은 생성기가 만드는 `<파일명>.json` 사이드카에만 있고,
**분석기는 사이드카를 절대 읽지 않습니다**. 채점기·UI만 비교용으로 씁니다. `.sigmf-meta`(SigMF)도
읽기 지원. 토큰 없는 임의 캡처는 UI 수동 입력 폼 또는 CLI `--fs/--fmt/--dtype/--be/--bitrev`로 지정.

## 복조 결과 저장

```bash
signus analyze FILE --save-iq out.f32       # 보정된 기저대역 IQ (f32 interleaved)
signus analyze FILE --save-symbols out.npy  # 복조 심볼 (complex64)
signus analyze FILE --save-bits out.txt     # Gray 디맵 비트 (--packed 는 .bin)
signus analyze FILE --diff --save-bits b.txt  # 차동 디맵 (회전 모호성 없음)
signus analyze FILE --report out.json
```
웹 UI에도 비트/심볼/리포트 다운로드와 배치 결과 CSV 내보내기가 있습니다.

## 파이프라인

**광대역 서베이 앞단** (`signus survey`) — 캡처에 신호가 여럿일 때:

```
스펙트로그램(Blackman-Harris) → 시간평균 PSD → 광폭 20퍼센타일 잡음바닥(신호 폭 무관)
→ 문턱 → 형태학 정리 → 신호별 상자 {중심주파수·대역폭·시간} → 인접 병합
└─ 각 신호: fc로 하향변환 → 저역통과 → 데시메이션(신호가 대역의 1/4~1/3 되도록)
   → 분류 관문: 정포락선 CV로 디지털/아날로그 판별
      ├─ 디지털 → 아래 단일신호 엔진에 투입
      └─ 아날로그 FM · 순수톤 → 성상도 강제 없이 그대로 보고
```

단일 신호 엔진 (`signus analyze`, 서베이가 신호마다 호출):

```
analytic(Hilbert) → DC블록 → 버스트 탐지(Otsu 이중임계, 전 버스트 → 선택/최강)
├─ FSK 게이트(정포락선 + 평균주파수 재중심 후 순시주파수 이봉성) → 주파수 판별 복조
└─ 선형: M제곱 반송파(적응 코히런트 적분) → 앨리어스 해소(스펙트럼 중심) → 하향변환
   → baud(|x|² 라인, 점유대역 불일치 시 창 내 후보 lock 경쟁) → 롤오프(점유대역)
   → 4sps 리샘플 → RRC 정합필터 → 블록별 Oerder-Meyr 타이밍(드리프트 추적)
   → 분류(C42 + 진폭 링 비율) → 정렬 → 결정지향 반송파 루프
   → [lock<60: 심볼간격 CMA 구제 → 부족하면 T/2 FSE, 등화 후 중립 재분류]
   → EVM/MER/lock/SNR(M2M4)
```

### 잡음 내성 (실측, 샘플전력 SNR dB)

| 변조 | 임계 SNR | 먼저 무너지는 단계 |
|---|---|---|
| BPSK | ≤ −4 | lock/EVM (탐지는 더 아래까지 버팀) |
| QPSK | 0 | classify (C42 경계) |
| 8PSK | 10 | **반송파 8제곱 스펙트럴 라인** |
| 16QAM | 2 | classify (링 비율) |
| 64QAM | ≤ 8 | lock/EVM |

M제곱 스펙트럼은 **비코히런트 평균**이라, 약한 톤(고차 대칭·저SNR)일수록 블록을 *줄여야* 이깁니다.
`blocks = clip(n/30000, 1, 8)` 적응 규칙이 8PSK 경계에서 **+2 dB**를 되찾습니다 (고정 blocks=4 대비).
FFT 크기를 4배 키우는 건 0 dB — 하지 마세요.

## 전수조사 (`signus sweep`)

- **CORE** (필수 100%, 53케이스): 5변조 × 정수/비정수 sps × 시드 + 32QAM + FSK 3종 + 차동 3종
  + 멀티패스 등화 2종 + 실수 PCM 4종 + 회귀(cfo=0, DC 오프셋, 버스트 패딩)
  + v3.1(2-ray FSE, 롤오프 0.05/0.08 폴백, 깊은 반송파 앨리어스).
  제원 오차 허용치 + lock + **BER=0** (회전·켤레 모호성 해소 후, 차동/FSK는 모호성 자체가 없음).
- **STRETCH** (`--tier full`, 리포트 전용): 저SNR 사다리, 롤오프 0.1~0.5, 큰 CFO, 드리프트 100ppm, sps=4.

```

signus/detect.py          광대역 신호 탐지 (스펙트로그램 → 신호별 상자)
signus/channelize.py      채널 추출 (하향변환 → 저역통과 → 데시메이션)
signus/triage.py          채널 분류 관문 (디지털 vs 아날로그/톤)
signus/dsp.py             선형 수신 DSP 전 단계
signus/classify.py        변조 분류 · 정렬 · 품질 · M2M4 SNR
signus/fsk.py             정포락선 게이트 · 주파수 판별 복조
signus/eq.py              CMA → 결정지향 블라인드 등화기 (심볼간격 + T/2 분수간격)
signus/spectrum.py        스펙트럼 · 워터폴 (표시 전용)
signus/pipeline.py        단일 신호 파이프라인 + 광대역 서베이 오케스트레이션
signus/gen.py             독립 신호 생성기 (수신기와 코드 미공유) — 개발기 전용, 인쇄물 제외
signus/lab.py             gen/dataset/sweep 명령 + BER 채점 하네스 — 개발기 전용, 인쇄물 제외
signus/cli.py             analyze/survey/serve (+ lab 이 있으면 gen/dataset/sweep 을 단다)
signus/server.py          stdlib 웹서버
signus/web/               vanilla 프런트 (애니메이션 성상도 · 워터폴 · 배치, CDN 없음)
```
