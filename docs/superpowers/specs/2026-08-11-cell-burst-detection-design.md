# 셀 기반 버스트 검출 — "눈 수준" find_bursts (1단계)

2026-08-11 승인. 범위: `signus/dsp.py`의 `find_bursts` 내부 교체. survey `detect()` 통합은
검증 후 별도 단계(2단계)로 미룬다 (2026-08-11 사용자 결정: "단계적, analyze 먼저").

## 왜

운용자는 워터폴(시간×주파수)에서 버스트를 눈으로 잡는다. 눈은 셀 하나하나를 그 셀의
잡음과 비교하므로 **대역 내 SNR**(처리이득 fs/bw 포함)을 공짜로 얻는다. 현행 코드는 둘 다
이 이득이 없다 — 실측 사각(2026-08-11, scratchpad/eye_demo2.py):

| 신호 (눈에는 전부 보임) | find_bursts | detect | 셀 뷰 |
|---|---|---|---|
| 협대역 5000샘플, 대역내 +12dB (광대역 0dB) | 못봄 | 아슬 검출 (6.9 vs 문턱 6.0) | 49% 점등 |
| **협대역 1500샘플, 대역내 +12dB** | **못봄** | **못봄** | **53% 점등, 오경보 1.3%** |

find_bursts는 전 대역 잡음을 합산해(+12→+3dB 희석), detect는 시간 평균을 해(듀티 희석)
못 본다. 셀 단위 초과 검출이 이 사각을 없앤다.

## 알고리즘 (C안: 열 점수 + 공유 코어)

1. STFT: nperseg≈256, hop=nperseg/2 (레코드가 짧으면 자동 축소; 창은 기존 detect와 같은
   계열). 셀 전력 P[f,t].
2. **빈별 바닥**: floor[f] = 그 빈의 시간축 중앙값. 빈 점유율 <50%인 신호에 강건하고,
   유색 잡음/스펙트럼 기울기를 빈 단위로 따라간다. 연속 신호는 자기 빈의 바닥이 자기
   수준이 되어 점수가 평평해짐 → 자연스럽게 [(0,n)] 폴백 (현행 의미 유지).
3. **열 점수**: score[t] = 상위 k개 빈의 (P/floor) 초과 평균 (k는 캘리브레이션으로;
   협대역=소수 빈이 강하게, 광대역=다수 빈이 고르게 — 둘 다 점수를 올린다).
4. 그 위에 기존 기계를 열 단위로 이식: 이력 이중 문턱 → 런 → 최소길이 게이트 →
   골짜기 병합(점수가 바닥 수준으로 돌아오지 않는 딥은 병합) → 스파이크 모양 검사
   (원시 |x|²) → 커버리지 가드(스파이크-사망 질량) → 전부 죽으면 [(0,n)].
5. 경계는 hop(≈128샘플) 양자화로 시작. 캘리브레이션에서 부족하면 검출 대역만 세밀
   정제를 추가한다 (스펙 확정 아님 — 필요 시).
6. 셀 전력/빈별 바닥 계산부는 작은 헬퍼로 분리 — 2단계(survey 2D 상자 통합)가 재사용.

## 계약 (불변)

시그니처 `find_bursts(x, fs) -> list[tuple[int,int]]`, 시간순, 폴백 [(0, n)], 임펄스 거부,
"애매하면 겸손(폴백)" 철학. analyze/파이프라인/웹은 한 줄도 안 바뀐다.

## dB 문턱의 원리 (2026-08-11 사용자 질문에 대한 설계 입장)

모든 dB 문턱은 절대값이 아니라 **그 레코드에서 추정한 바닥 대비 상대값**이고, 상수가
실제로 서술하는 것은 **오경보 확률**이다: 평균화된 잡음의 상대 요동은 잡음 세기와 무관하게
통계로 고정되므로(≈1/√win), "바닥+5dB"는 9σ의 dB 표기일 뿐이다. 스케일/이득 불변.
한계 세 가지를 명시한다 — (1) 비가우시안(임펄스성) 잡음: 같은 dB가 더 적은 σ (스파이크
가드가 부분 방어), (2) 유색 잡음: 이 설계의 빈별 바닥이 흡수, (3) 시변 잡음: 레코드당
1회 바닥 추정의 정상성 가정 — 실신호에서 증상이 보이면 국소 바닥으로 확장(후속).

## 검증

- TDD: 사각 케이스(협대역 1500샘플·광대역 0dB·대역내 +12dB)가 첫 RED 테스트.
- 기존 find_bursts 테스트 전부(현재 9개) 그대로 그린 = 광대역 동작 보존 증명.
- 그리드에 (대역폭, 대역내 SNR) 축 추가해 신구 F1 대조 + 잡음 전용 오경보 0.
- 적대 패스: FSK(빈을 뛰는 톤), 처프(전 빈 스침 — 열 점수가 계속 높아 한 덩어리/전체가
  정답), 임펄스, 유색 잡음(기울인 바닥), 고듀티.
- sweep 합불 신구 대조. 합성 생성기는 개발기 전용(gen.py) — 장비 코드에는 안 들어간다.
